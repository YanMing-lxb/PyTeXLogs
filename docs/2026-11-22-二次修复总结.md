## 1. P1 修复

| 编号 | 问题 | 修复结果 | 回归 |
|---|---|---|---|
| P1-1 | `run_pipeline(auxdir=...)` 未给 `jobname` 时静默空报告 | `core.engine._infer_jobname()`：`root_file` 优先；否则 `main.log`、其他 `.log`、带 `\documentclass` 的 `.tex` | 动态探针 0 → `pdflatex, 1 条` |

| P1-4 | BibTeX 裸 `---while reading file` 重复记录并带上一行文本 | 裸 aux 行由多行扫描唯一记录；`_parse_line_with_unified_error` 在行首命中时直接返回，不再用 `last_line` 兜底 | 裸 aux 由 2 条错误 → 1 条正确错误 |

## 2. P2 修复

| 编号 | 问题 | 修复结果 |
|---|---|---|
| P2-1 | stream / 无 `rich` 回退丢类别标签 | `_print_to_stream()` 优先用调用方 `plain`；`_FallbackConsole` 直接输出 plain；`emit()` fallback 分支传 plain。`[一般编译]` 等字面标签保留 |
| P2-2 | `write_report()` 契约不符，失败时可能留临时文件/异常 | `mkdir`、`mkstemp`、`write`、`replace` 全在 `try` 内；失败关闭 fd、清理临时文件并返回 `None` |
| P2-3 | `.xlg` 没有路由 | `Xindy` 注册 `.xlg`；`parse_log_file("main.xlg")` → `xindy, 2 条` |
| P2-4 | 陈旧 `.bcf` 让 `.blg` 误判 Biber | `sniff_bib_tool` 先看 `.blg` 头部：明确 `biber/biblatex` → biber，明确 `bibtex` → bibtex；无头部特征才看 `.bcf` |
| P2-5 | `--no-hints` 对 JSON/CSV/SARIF 无效 | 三条导出入口统一传 `include_hints=show_hints`；JSON 有回归 |
| P2-6 | i18n 缺 `external/custom` | 新增“外部工具”“自定义解析”英文翻译；`--lang en` 无中文残留 |
| P2-7 | `show_log_entries()` 遇报告对象崩溃或静默空输出 | 新增 `ReportEntry` / `ToolResultReport` 归一化；`ParsedLog` 列表保持原样 |

## 4. 引用与路由补充

- `RefChangeTracker.detect_mode()` 先扫 `.aux`：`\abx@aux@cite` / `\abx@aux@defaultrefcontext` → biber；`\bibdata` / `\citation` / `\bibcite` → bibtex；再回退 `.bcf`。陈旧 bcf 不再覆盖真实 aux 标记。
- `sniff_bib_tool()` 的头部优先策略让“先用 BibTeX、后残留 bcf”的目录不再误判。
- `.xlg` 只加入 Xindy 的显式后缀，不加入默认步骤规划，避免将普通 `.log` 之外的索引日志重复消费。

## 7. 兼容性说明

按用户确认，当前只有 PyTeXMK 使用本库，兼容性可忽略。以下行为变化需 PyTeXMK 适配：

- `run_pipeline(auxdir=...)` 会自动推断 `jobname`，不再默认空 jobname。
- `aggregate_stats()` 对未知 `group_by` 抛 `ValueError`，不再静默回退。
- `parse_file()` 对 parser 返回 `None` 抛 `TypeError`，不再静默忽略。
- `--no-hints` 现在对 JSON/CSV/SARIF 全部生效。
