PyTeXLogs 0.6.3 · terminal summary

摘要版式预览：固定宽度可配置 + 悬挂缩进

默认仍为 74 列，但 width / summary_width / --width 可由调用方覆盖；折行后每行开头与首行文本起始列对齐。以下为 rich 真实渲染（深色主题）。

版本 0.6.3默认 74 列最小 40 列颜色：error / warning / info + dim对照 0.6.2 旧版
A

宽度与对齐

同一组条目在 74 / 60 / 40 列下的真实输出。注意条目续行、hint 续行与命令行的缩进。

01

默认 74 列 · 中英混排摘要

默认版式保持 74 列；等级标题沿用旧版 `====` 居中横幅，分类标题沿用 `+--` 框线，条目正文悬挂缩进。

print_summary(..., width=74) / run_pipeline(..., summary_width=74)rich / truecolor

接入方式

PyTeXMK / 库调用

print_summary(..., width=console.width)
run_pipeline(..., summary_width=console.width)

CLI

pytexlogs check main.log --width 60
宽度低于 40 自动收敛；文本流仍保持纯文本可复制。
